# Zigbee Atlas

Instalace, požadavky a význam mapy jsou v [README repozitáře](https://github.com/xxxnet/zigbee-atlas#readme).

Nejdřív nech `zigbee2mqtt_directory: auto`. Pokud najde více sítí, vyber jedinou datovou složku v nastavení aplikace. Z2M musí zapisovat debug logy do souboru. Atlas nastavení Z2M automaticky nemění.

První verze podporuje pasivní celé trasy pro adaptéry Ember/EZSP. Pro jiné adaptéry mohou být dostupné stavy a příjmy, ale žádné spoje. ZHA není podporované.
